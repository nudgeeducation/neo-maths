NEO Mathematics: Accuracy, Powers and Scale

Rounding to significant figures

Driving Question: How can we make a number easier to use while keeping it close to its original value?

Lesson type: Precision Lens exploration, boundary reasoning and supported practice.

Stepping Stone: round positive integers and decimals to a stated number of significant figures.

NEO Cornerstones: Connection · Movement · Reflection · Creativity · Rest · Nutrition

45-minute shape: Connect 8 · Move 18 · Practise 10 · Reflect/Create 5 · Rest/Nourish 2 · Evidence 2

🌱 Open Learner Guide 📘 Open Supporting Adult Guidance
🌿 Connection — Which digits carry the size of a number?

What to do: compare the original number with its rounded version. Decide which digits keep the most useful information about size.

What you are trying to notice: rounding changes a number, but the leading digits can preserve its approximate magnitude.

Original value

48,271

Rounded value: 48,000

Question: Which digits show that both values are about forty-eight thousand?

Try to explain what remains useful before opening Movement.

Carry this idea forward: significant figures begin at the first non-zero digit because that is where the number first communicates its scale.
🚶 Movement — How does the Precision Lens move?

What to do: choose a number and a precision. Predict the rounded value, then reveal the lens.

What you are trying to notice: the lens begins at the first non-zero digit, keeps the required digits and uses only the next digit to decide.

🧭 Precision Lens

Carry this idea forward: find → keep → decide → check the columns. The kept digits must stay in the columns they started in, so any whole-number column they leave behind is held by a zero.
🪞 Reflection — Why does the deciding digit work?

What to do: use the Boundary Explorer, then complete the reflection sentence.

A zero is significant when...

What you are trying to notice: rounding chooses the nearer of two possible rounded landmarks. The halfway point explains why 5 rounds up.

🎨 Creativity — Can I make the rounding decision visible?

What to do: create a mini teaching card for one whole number and one decimal.

  1. Write the original number.
  2. Mark the first significant digit.
  3. Underline the kept digits.
  4. Circle the deciding digit.
  5. Name the column each kept digit sits in.
  6. Write the rounded value and explain why it is sensible.
🌙 Rest — How can I reduce the process to four calm actions?

Use this quiet route. Look away from the screen, then retrieve it in your own words:

find → keep → decide → check the columns

The last step asks one question: are my kept digits still in the columns they started in?

🥣 Nutrition — What is this lesson nourishing?

This lesson uses intellectual nourishment. It nourishes attention to magnitude and confidence with crowded numbers.

🌱 Magnitude
I notice the overall size before calculating.
🌱 Attention
I distinguish kept and deciding digits.
🌱 Judgement
I choose a sensible nearby landmark.
🌱 Confidence
I can organise a number even when it looks crowded.
🏠 Final Task — Build a Precision Explainer

Make one rounding decision clear

What to do: choose one whole number and one decimal and create a clear explanation for each.

  • identify the first significant digit;
  • state the chosen precision;
  • mark the deciding digit;
  • name the column each kept digit occupies;
  • write the rounded value;
  • explain why the answer is sensible.
