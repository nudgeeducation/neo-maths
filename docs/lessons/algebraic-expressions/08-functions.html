NEO Mathematics: Algebraic Expressions and Identities

Function notation, domain and range

Driving Question: What goes in, what comes out, and what is not allowed?

Lesson type: Core — a rule as a machine: inputs, outputs, and the inputs it cannot take.

Stepping Stone: understand a function as a mapping where each input gives exactly one output; use function notation f(x) and f: x ↦ …; evaluate and solve with it; find the domain, including values that must be excluded; and find the range.

You will need: substitution, solving a linear equation, and the facts that you cannot divide by zero or take the square root of a negative number — and the optional ✏️ Scratchpad. No calculator needed.

🌿 Connection — The function machine

🔤 The idea for this lesson

A function is a rule that turns each input into exactly one output. We write f(x) = 2x − 1, or f: x ↦ 2x − 1, and f(3) means "the output when the input is 3". The inputs a function can take make its domain; the outputs it can produce make its range. Some rules cannot take certain inputs — those must be excluded from the domain.

What to do: choose a machine. Feed it numbers: each one draws an arrow on the mapping diagram. Try to jam it! Then answer its questions.

What you are trying to notice: a machine jams when it would divide by zero or take the square root of a negative number. And some outputs never come out, whatever you feed in.

🚶 Movement — Notation moves

What to do: use the notation for f(x) = 3x + 4.

What you are trying to notice: whatever is in the brackets replaces x — a number, a letter or even an expression.

✍️ f(x) = 3x + 4

Carry this forward: f(□) means: put □ where x was.

🪞 Reflection — Domain and range on a graph

What to do: look at each graph. The allowed inputs are shaded green along the x-axis; the outputs reached are shaded gold along the y-axis. Describe the domain, then the range.

What you are trying to notice: the domain is how far the graph reaches left and right; the range is how far it reaches up and down.

🎨 Creativity — Function detective

What to do: find the rule behind each set of arrows — then design functions of your own that do exactly what is asked.

What you are trying to notice: a function can be found from enough input–output pairs; and you can build a function to exclude any input you choose.

🌙 Rest — A pause to let it settle

A machine that takes almost anything — except one number it can never accept. Take a slow breath.

Notice one thing: the whole unit has been about the same question in different clothes: when are two things really the same, and what is allowed? Functions ask it about inputs and outputs.

🍎 Nutrition — What this feeds

Mode: intellectual. The mathematics is the nourishment, so we name honestly what the learning feeds.

What it feeds: today feeds knowing the limits of a rule. Every rule — in mathematics, in a spreadsheet, in a computer program — works for some inputs and fails for others. Knowing where a rule breaks is as useful as knowing how it works.

Carry one idea forward: before you trust a rule, ask what it cannot take.

🛠️ Final Task — Inputs, outputs and limits

Your task: show that you can use function notation and find domains and ranges.

  • For f(x) = 4x − 3, find f(2), f(−1) and f(a), and solve f(x) = 17.
  • For g(x) = x² − 4 with domain {−2, −1, 0, 1, 2}, draw a mapping diagram and write the range.
  • State the value that must be excluded from the domain of h(x) = 5/(x + 3), and the domain of k(x) = √(x − 6). Explain why.
  • Explain why the range of m(x) = x² + 1 is m(x) ≥ 1.
  • stretch Design a function whose domain excludes exactly two values, 1 and −1. Explain how you know.

Submission choices: an annotated Scratchpad image, a photographed page, a short slideshow, or a spoken/video walkthrough.
