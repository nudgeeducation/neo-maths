NEO Mathematics: Equations, Inequalities and Simultaneous Relationships

A line is a set of solutions

Driving Question: If x and y can both change, what does “solution” mean now?

Lesson type: Core — the opening lesson of the algebra unit, where solving becomes keeping the balance.

Stepping Stone: understand a linear relationship in two variables as a set of solutions — every point on the line y = mx + c is a solution and every solution is a point on the line — and read solutions off the line.

You will need: the four operations and their inverses, working with negative numbers, and the optional ✏️ Scratchpad. No calculator needed today.

🌱 Open Learner Guide 📘 Open Supporting Adult Guidance
🌿 Connection — One equation, many answers

🔤 The idea for this lesson

Every equation so far had one unknown and (usually) one answer. But an equation with two unknowns, like x + y = 6, is different: (0, 6) works, so does (1, 5), and (2, 4)… there are infinitely many pairs that make it true. A solution is now a pair (x, y), and if you plot all of them they line up — the equation's answers are a straight line.

What to do: add solution pairs to x + y = 6 one at a time and watch them appear. Then join them.

What you are trying to notice: the pairs are not scattered — they fall exactly on a straight line. Every pair that works is a point on it; every point on it is a pair that works.

📍 Many pairs, one line

Carry this forward: with two unknowns, a solution is a pair (x, y) — and the whole set of solutions is a line.

🚶 Movement — From a table to the line

What to do: a relationship like y = 2x + 1 gives a y for every x. Work out y for each x in the table; each pair plots as a point, and the points build the line.

What you are trying to notice: the table and the line are the same set of solutions, shown two ways. Every row is a point; the points are never scattered — they form the line.

📊 Fill the table, build the line

Carry this forward: a table of (x, y) pairs and the line are two views of one solution set.

🪞 Reflection — On the line, or not?

What to do: the line y = mx + c is drawn, and a point is marked. Decide: is it a solution (does it make the equation true)? Then the tool checks by substituting.

What you are trying to notice: a point is a solution exactly when it lies on the line. Substituting its x and y either makes the equation true (on the line) or not (off it). The line is the set of all solutions — nothing more, nothing less.

✅ Test the point against the equation

Carry this forward: a point is a solution precisely when it lies on the line; the line is the whole solution set.

🎨 Creativity — Read a solution off the line stretch

What to do: because the line holds every solution, you can read one off. Given an x, find the y the line pairs with it (or the other way round). Answer, then see the point highlighted on the line.

What you are trying to notice: the line works both ways — give it an x and it hands back a y; give it a y and it hands back an x. Each is one solution pair, picked from the infinite set.

🔎 Pick a solution from the line

🌙 Rest — A pause to let it settle

There is a quiet shift happening here: an answer has grown from a single number into a whole line of possibilities. Nothing has been lost — the line simply holds every pair that works, all at once, in one clean stroke. Take a breath and let the idea widen.

Notice one thing: did "solution" feel different once it became a pair you could see on a graph, rather than one number to find? Just notice how the meaning stretched.

You can pause here and return whenever you are ready.

🍎 Nutrition — What this feeds

Mode: intellectual. The mathematics is the nourishment here, so we name honestly what the learning feeds.

What it feeds: today feeds a taste for seeing the whole at once — the leap from hunting one answer to holding an entire set of them in a single picture. That a line can be a set of solutions is one of the most powerful ideas in algebra: it lets a graph answer questions a single number never could, and it is the doorway to solving two relationships together.

Carry one idea forward: a straight line is not just a shape — it is every (x, y) pair that obeys a rule, drawn all at once.

🛠️ Final Task — Evidence for today

Your task: show that a line is the set of all solutions of its equation.

  • Take a relationship like y = 2x + 1. Make a table of at least four (x, y) pairs and plot them — they should fall on one line.
  • Test two points not in your table: one on the line and one off it. Substitute each into the equation and say which is a solution.
  • Read one new solution straight off the line (choose an x, read its y), and check it by substituting.
  • stretch Explain in a sentence why every point on the line is a solution and every solution is a point on the line.

Submission choices: an annotated Scratchpad image, a plotted graph with your table, a short spoken explanation, or a poster linking the table, the line and the equation.
