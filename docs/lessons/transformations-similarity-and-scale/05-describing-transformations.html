NEO Mathematics: Transformations, Similarity and Scale

Describing transformations fully

Driving Question: What must a full description include?

Lesson type: Core — naming a transformation and giving every detail.

Stepping Stone: given an object and its image, name the single transformation and describe it fully: a reflection with its mirror line, a rotation with its centre, angle and direction, a translation with its column vector.

You will need: Lessons 1 to 4 — and the optional ✏️ Scratchpad.

🌿 Connection — Reflected, rotated or translated?

Start here: look at the object ABC and its image A′B′C′. Was it reflected, rotated or translated? Choose the transformation.

What you are trying to notice: the image gives clues to the type. A reflection turns the shape over; a rotation turns it; a translation slides it, so every side still points the same way as before.

🔎 Reflected, rotated or translated?

🔤 The idea for this lesson

A full description names the transformation and gives every detail, so that only one image fits it:

  • a reflection: the mirror line, as an equation;
  • a rotation: the centre, the angle and the direction (clockwise or anticlockwise);
  • a translation: the column vector.

It must be a single transformation: one move, not two.

Today's main activity, the Transformation Detective, is next, in Movement.

🚶 Movement — The Transformation Detective (today's main activity)

What to do: for each case, choose the type of transformation, then give every detail. Press Apply my description: the lesson carries out exactly what you wrote and draws the result dashed. A full, correct description lands exactly on A′B′C′.

What you are trying to notice: the type comes from the picture; each detail comes from measuring. If a detail is missing or wrong, the dashed outline shows where your description really goes.

🕵️ The Transformation Detective

Finding the details: a mirror line is halfway between each point and its image. A centre of rotation is the same distance from each point and its image. A column vector is counted from the object to the image.

What you are trying to notice: how many details each transformation needs before only one image fits.

🎨 Creativity — Describe, then swap

What to do: first, make your own move. Choose a brief, write a full description, and the lesson draws your image. Then swap: the lesson makes a mystery move for you to describe.

What you are trying to notice: a full description works in both directions: it makes exactly one image, and an image can be traced back to exactly one description.

🍎 Nutrition — What this feeds

Mode: practical. Today the mathematics feeds instructions that machines follow exactly.

What it feeds: animation and design software asks for every detail of a move: “rotate 90° clockwise about this point”, “flip about this axis”, “move by 120 pixels across and 40 down”. A machine cannot guess, so a description that leaves out the centre or the direction cannot be carried out. Embroidery machines, laser cutters and game engines work the same way.

Carry one idea forward: type first, then every detail.

🛠️ Final Task — The full description file

Your task: make a short file of three moves, one of each type, each with a full description and the evidence.

  • Draw one shape and three images: a reflection, a rotation and a translation.
  • Write a full description of each.
  • For each, show how you found the details: the halfway line, the centre, or the count from object to image.
  • stretch Write a vague description of one move, and show two different images that both fit it.
