    💡 How constructions work here: build corners with Construct → Point on object or Construct → Intersection(s) — never the plain Point tool. A point built by a command stays attached to its arcs, so your construction holds together when you drag. A point dropped by eye is free and will drift.
    Pick an instrument on the left to draw, or use Select to choose objects then apply a menu action. Try: Point ×3, then Select all three and Construct → Angle bisector.
