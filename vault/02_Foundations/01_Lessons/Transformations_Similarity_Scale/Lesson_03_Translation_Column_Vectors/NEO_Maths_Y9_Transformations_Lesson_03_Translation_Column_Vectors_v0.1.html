🌿 Connection — The Vector Mover (today's main activity)

🔤 The idea for this lesson

A translation slides a shape: every point moves the same distance in the same direction. The image is the same shape and size, facing the same way.

A column vector records the slide with two numbers, one written above the other: 3−2 means 3 right and 2 down. The first number (written above) is the horizontal move: right +, left −. The second number is the vertical move: up +, down −.

What to do: change the two numbers with −1 and +1, and watch the image slide. Read the vector aloud in words. Then switch to Find the vector: slide the shape onto each dashed outline.

What you are trying to notice: every arrow is the same length and points the same way. The first number moves the shape horizontally; the second moves it vertically.

🌙 Rest — A pause to let it settle

A slide keeps everything the same, just somewhere else. Take a slow breath.

Notice one thing: think of something that slides without turning: a drawer, a lift, a sliding door. Which way does it move, and how far?

You can pause here and return whenever you are ready.

🍎 Nutrition — What this feeds

Mode: practical. Today the mathematics feeds how moves are given to machines.

What it feeds: games, animations and robots move things using pairs of numbers like column vectors: “move 3 across and 2 down” each frame or each step. Plotters and embroidery machines follow lists of such moves to draw a design, and a delivery robot's route is a chain of moves added together.

Carry one idea forward: across first, then up or down.

🛠️ Final Task — A journey of translations

Your task: move a shape on a journey of three translations, and find the single vector for the whole journey.

  • Choose three column vectors, and translate a shape by each in turn.
  • Write each move in words and as a column vector.
  • Find the single column vector from the start to the finish, and check it.
  • stretch Find the column vector that brings the final image straight back to the start.
