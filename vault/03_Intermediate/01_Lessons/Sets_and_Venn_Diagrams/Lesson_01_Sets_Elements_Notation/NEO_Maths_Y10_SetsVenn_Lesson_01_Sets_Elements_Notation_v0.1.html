🌿 Connection — The Set Sorter (today's main activity)

Start here: you already sort things into sets: the apps on your phone's home screen, the songs in a playlist, the subjects you study. Mathematics gives sorting a precise language.

🔤 The idea for this lesson

A set is a collection with a clear rule: for anything at all, you can say whether it belongs. Each thing in the set is an element. Write a set in curly brackets, by listing its elements, {2, 3, 5, 7}, or by describing them, {prime numbers less than 10}. The order does not matter, and each element is listed once.

5 ∈ A means “5 is an element of A”; 4 ∉ A means “4 is not an element of A”. n(A) is the number of elements in A. The universal set, ℰ, holds everything we are talking about; a set with nothing in it is the empty set, ∅.

What to do: here ℰ = {1, 2, 3, …, 24}. Choose a rule for the set A, then tap numbers to move them into or out of A's circle. Watch the listing, n(A) and the ∈ / ∉ statement. Press Check my set. Then try Guess the rule.

What you are trying to notice: the rule decides the set. What happens to n(A) for different rules? Is there a rule that gives no elements at all?

🗂️ The Set Sorter

Carry this forward: a set is fixed by its rule. List or describe it in { }; ∈ means “is an element of”; n(A) counts the elements; ∅ is the empty set.

🚶 Movement — The Membership Machine

What to do: each object arrives at the machine's gate. Decide before it does: is the object an element of the set (∈) or not (∉)? If you like, stand or raise a hand for ∈ and stay still for ∉.

What you are trying to notice: only the rule matters, so test the object against it.

🪞 Reflection — Well-defined or not?

What to do: a set needs a clear rule. Decide whether each collection is well-defined: could everyone agree on exactly what belongs?

What you are trying to notice: words like “big” or “good” are matters of opinion, so they do not make a set.

🍎 Nutrition — What this feeds

Mode: practical. Today the mathematics feeds how you organise information.

What it feeds: today feeds sorting with a clear rule. Filters on a shopping site, search results, folders on a computer and playlists all build sets from rules. When a rule is clear, everyone gets the same result; when it is vague, results disagree.

Carry one idea forward: what is the rule?

🛠️ Final Task — Sets around you

Your task: choose a universal set from your own life or from numbers (for example, the numbers 1 to 30, or the days of a month).

  • Define three sets inside it, each in two ways: by listing and by describing.
  • For each set, write one ∈ statement and one ∉ statement, and give n.
  • Define a set that turns out to be the empty set, ∅, and explain why it is empty.
  • stretch Explain why a square number has an odd number of factors.
