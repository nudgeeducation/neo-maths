NEO Mathematics: Sets and Venn Diagrams

Subsets, the empty set and sets defined algebraically

Driving Question: Can a set hide inside another, or be empty?

Lesson type: Core — sets described by a rule, sets inside sets, and the set with nothing in it.

Stepping Stone: understand subsets (A ⊂ B) and the empty set, ∅, and list sets defined algebraically, such as {x : x is an integer, −2 ≤ x < 3}.

You will need: Lessons 1 and 2, inequalities such as 2 < x ≤ 6, and the optional ✏️ Scratchpad.

🌿 Connection — Which integers fit?

Start here: an inequality is a rule. Tap every integer that fits it, then check. If none fits, say so.

What you are trying to notice: < leaves the end number out; ≤ lets it in. Sometimes nothing fits at all.

🔍 Which integers fit?

🔤 The idea for this lesson

{x : x is an integer, 2 < x ≤ 6} is a set defined algebraically. Read it as “the set of x such that x is an integer and 2 < x ≤ 6”. The colon means “such that”. Listed, it is {3, 4, 5, 6}.

A ⊂ B, read “A is a subset of B”, means every element of A is also in B. On a Venn diagram, A's circle sits inside B's.

The empty set, ∅, has no elements, so n(∅) = 0. A rule that nothing fits gives ∅.

Today's main activity, Inside, overlapping or apart?, is in Reflection.

🚶 Movement — The Set-Builder Decoder

What to do: change the numbers at each end with −1 and +1, and tap a symbol to switch it between < and ≤. Watch the number line and the list. Say the rule aloud: “the set of x such that …”.

What you are trying to notice: an open circle leaves an end out and a filled circle lets it in; moving an end by one, or switching its symbol, adds or removes one integer.

🔓 The Set-Builder Decoder

Carry this forward: to list a set defined algebraically, find the first and last integers that fit, then list everything between. If nothing fits, the set is ∅.

🪞 Reflection — Inside, overlapping or apart? (today's main activity)

What to do: read the two sets. Decide how they sit together: is one inside the other, do they overlap, or are they apart? Then show why. The Venn diagram appears when you decide.

What you are trying to notice: A ⊂ B needs every element of A to be in B, and one element outside is enough to show it is not. When A ⊂ B, A ∩ B = A and A ∪ B = B.

🪆 Inside, overlapping or apart?

Carry this forward: to test A ⊂ B, check every element of A. To show it is not true, one element of A outside B is enough. The empty set is a subset of every set: it has no element that could be outside.

🎨 Creativity — Rule writer

What to do: set the rule to make each set in the brief, then check. There is often more than one rule that works.

What you are trying to notice: different rules can describe the same set; a set is decided by its elements, not by how it is written.

🍎 Nutrition — What this feeds

Mode: practical. Today the mathematics feeds how you read a range.

What it feeds: today feeds reading ranges exactly. “Under 16” on a ticket means age < 16, so a 16-year-old does not fit; “16 and over” means age ≥ 16. A price filter “£10 to £20” might mean 10 ≤ price ≤ 20 or 10 ≤ price < 20, and the difference decides whether a £20 item appears. Asking “is the end included?” is the same question as < or ≤.

Carry one idea forward: is the end in, or out?

🛠️ Final Task — My sets inside sets

Your task: choose a universal set ℰ and two sets A and B with A ⊂ B. Define at least one of them algebraically, as {x : …}.

  • List both sets and draw the Venn diagram, with A's circle inside B's and every element in its region.
  • Explain why A ⊂ B, and give an element that shows B is not a subset of A.
  • Write a rule in set-builder notation that gives ∅.
