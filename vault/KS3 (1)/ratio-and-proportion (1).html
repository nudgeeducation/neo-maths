NEO Mathematics KS3: Ratio and Proportion

Driving Question: Can maths help us share, scale and sustain things fairly?

Lesson focus: scaling recipes, equivalent ratios, ratio tables and proportional reasoning.

Stepping Stones: use ratio notation; recognise equivalent ratios; solve problems involving direct proportion; use multiplicative reasoning; and explain why quantities must scale by the same factor.

NEO Cornerstones: Connection, Movement, Creativity, Reflection, Rest and Nutrition.

🌿 Connection — What is connected to what?

Ratio shows a relationship

A ratio compares quantities. In a recipe, the ingredients are connected. If the number of people changes, each ingredient must change by the same multiplier.

Base smoothie recipe for 2 people:
1 banana : 200 ml milk : 80 g oats : 2 tsp honey

Connect the quantities

  • For every 1 banana, there are 200 ml of milk.
  • For every 2 people, there is 1 banana.
  • For every 2 people, there are 80 g of oats.

Sentence stem: “The quantities are connected because…”

Misconception to watch for

Additive mistake: “If I add 2 more people, I add 2 more bananas.”

Repair: In ratio, we usually need multiplicative reasoning. If people double, each ingredient doubles.

🌙 Rest — Where is the pause?

Calm consolidation

Ratio can feel easier when we slow the problem down. Use this pause structure:

  1. Find the original number of people.
  2. Find the new number of people.
  3. Work out the multiplier.
  4. Use the same multiplier for every ingredient.
  5. Check whether the answer is reasonable.

Helpful self-talk: “I do not need to solve the whole recipe at once. I can find the multiplier first.”

Regulation pause

  • Take three slow breaths.
  • Look away from the screen for 20 seconds.
  • Say the multiplier out loud or write it down.
  • Return to the table one row at a time.
🥣 Nutrition — How does this maths help us sustain life?

Mathematics for choices

Ratio helps us scale food fairly, compare quantities and make decisions about health, cost and sustainability. Maths can support decisions, but it does not make the human judgement for us.

Mini inquiry

If you are making smoothies for a group, which priority matters most?

  • Everyone gets the same amount.
  • The recipe is affordable.
  • The recipe is balanced.
  • The recipe uses ingredients people like.
  • The recipe is easy to prepare.

Reflection sentence: “Ratio helps with this decision because…”
