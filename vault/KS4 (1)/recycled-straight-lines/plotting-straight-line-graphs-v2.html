NEO Mathematics: Plotting Straight Line Graphs

Driving Question: Can a straight line help us predict what happens next?

Lesson focus: plotting and interpreting straight-line graphs using y = mx + c, with gradient as rate of change and the y-intercept as starting value.

Stepping Stones: connect equations, tables and graphs; identify gradient as rate of change; identify the y-intercept as starting value; interpret positive, negative and zero gradients; write equations of straight lines; and explain linear models in context.

NEO Cornerstones in this lesson: Connection, Movement, Creativity, Reflection and Rest.
Nutrition is not forced because the mathematics does not need a food, health or nourishment context.

🌱 Open Learner Guide 📘 Open Supporting Adult Guidance
🌿 Connection — How are equation, table and graph connected?

Interactive investigation 1: One relationship, three representations

A straight-line equation, a table of values and a graph can all describe the same relationship. In this investigation, you will change the equation and then look for the same start and change in the table and graph.

What you are trying to notice:
  • c tells you the starting value: the value of y when x = 0.
  • m tells you the repeated change in y each time x increases by 1.
  • The equation, table and graph should all show those same two facts.

Follow these steps:

  1. Use the sliders to choose a value for m and c.
  2. Read the equation shown. Before revealing the graph, predict where the line will cross the y-axis and whether it will rise, fall or stay horizontal.
  3. Use Sketch prediction if drawing helps you think.
  4. Select Reveal / update graph.
  5. Compare the equation, table and graph. Find the starting value c and the repeated change m in all three.
  6. Change only one slider and repeat. Ask yourself: what changed, and what stayed the same?
m = 2
c = 3

Connection to carry forward: if two representations describe the same line, they must agree about the starting value and the change for each 1 in x.

🌿 Connection — How can the same relationship appear in four different forms?

Interactive investigation 2: Representation Matcher

You have just seen one relationship appear as an equation, table and graph. Now the representations have been separated and mixed up. Your job is to reconnect the ones that describe the same linear relationship.

Follow these steps:
  1. Read the story. Find the starting amount and the amount that changes each time x increases by 1.
  2. Translate those two clues into c and m.
  3. Choose the equation with the same m and c.
  4. Choose the table description with the same starting value and repeated change.
  5. Choose the graph description with the same y-intercept and gradient.
  6. In Explain your match, say which clue gave you m and which clue gave you c.
  7. Select Check match. Use the Socratic prompt or hint if you want support before checking.

Useful route: find the start first, then find the change. You do not need to match everything at once.

🚶 Movement — What exactly moves when m or c changes?

Interactive investigation 3: Line Change Tracker

In Connection, you saw m and c appear in three representations. Now investigate the movement of the line itself. You will begin with one line, make one deliberate change, and compare the before-and-after graphs.

Follow these steps:
  1. Look at the starting line shown in blue.
  2. Choose one change: increase or decrease m, or increase or decrease c.
  3. Before applying the change, choose what you predict the graph will do.
  4. Select Apply my change. The changed line appears in purple while the original blue line stays visible.
  5. Compare the two lines. Read the change report and decide whether your prediction matched.
  6. Try several changes. Change only one thing at a time so you can identify its effect.
Blue: starting line Purple: changed line
🪞 Reflection — What evidence tells me which line I am looking at?

Interactive investigation 4: Line Detective

This time the equation is hidden. You are given clues about a line and must reconstruct its gradient, y-intercept and equation. Treat each clue as mathematical evidence.

Follow these steps:
  1. Read the clue carefully.
  2. Find the clue about where the line crosses the y-axis. That gives you c.
  3. Find the clue about how y changes when x increases by 1. That gives you m.
  4. Enter m and c.
  5. Use those values to write the equation in the form y = mx + c.
  6. Select Check line. If the clue feels hard to hold in mind, plot or annotate it on the Coordinate Scratchpad.

🎨 Creativity — What story could this line tell?

Interactive investigation 5: Human Graph Story Builder

Now reverse the process. Instead of being given a story and finding the line, you will choose the mathematical relationship and create a situation in which the gradient and starting value have a clear meaning.

Follow these steps:
  1. Give your model a title.
  2. Decide what x measures and what y measures. Include units where helpful.
  3. Choose m. This must mean: how much y changes for each increase of 1 in x.
  4. Choose c. This must mean: the value of y when x = 0.
  5. Write the story in words. Explain what your m and c mean in this situation.
  6. Describe one place where the straight-line model might stop being realistic.
  7. Select Generate model card, inspect the equation and table, then select Review model.
🌙 Rest — How can I make four representations feel manageable?

You do not have to hold the equation, table, graph and story in your attention at the same time.

One representation at a time:
  1. Start with the equation. Find m and c.
  2. Check the table. Does y change by the same amount when x increases by 1?
  3. Look at the graph. Where does it cross the y-axis? Which way does it rise or fall?
  4. Add the story last. What could the rate and starting value mean?

Pause after any one step. The relationship will still be there when you return.
